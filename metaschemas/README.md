# JSON Schema 2020-12 meta-schemas

The dialect meta-schema and the seven vocabulary meta-schemas OBI-10 names,
as published with JSON Schema 2020-12 (https://json-schema.org/draft/2020-12),
copied verbatim from the copies github.com/santhosh-tekuri/jsonschema/v6
v6.0.3 carries. Core embeds them in a value contract's bundle when a schema
references one the document and its resources do not declare.
